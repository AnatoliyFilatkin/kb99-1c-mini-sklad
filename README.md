# kb99-1c-mini-sklad
Прохождение стажировки в 1С:Франчайзи КБ99
Внутри cf создан на учебной конфигурации ,скачанной с сайта инфостарт.
Проект «Мини-Склад» (по главам 1–5): Создана учебная конфигурация с минимальным контуром учёта:
Справочники: Товары, Контрагенты.
Документы: Поступление, Реализация (формы, движения — **базовые**).

**Базовые, по умолчанию, не прописаны в ТЗ, поэтому не созданы разработчиком. Нет задачи какие регистры должны быть созданы, базовых регистров нет.**

Интерфейс: добавьте объекты в подсистему «Мини-Склад», **выведите команды на панель**. 

**Не описаны какие команды нужно вывести на панель. На панель выведены стандартные команды "Создать" справочников и документов.
